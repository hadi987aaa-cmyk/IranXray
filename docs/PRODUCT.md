# Shaghali — راهنمای کوتاه

کلاینت شخصی برای کانفیگ‌های v2ray با هسته‌ی Xray، بهینه‌شده برای شبکه‌ی ایران.

## نصب

۱. فایل `Shaghali_<version>_arm64-v8a.apk` را از صفحه‌ی Releases بگیرید.
۲. اگر اندروید پیام «Blocked by Play Protect» داد، در تنظیمات Play Store گزینه‌ی
   *Scan apps with Play Protect* را خاموش کنید (این پیام مربوط به امضای دیجیتال است، نه ویروس).
۳. نصب کنید.

نسخه‌ها با یک کلید ثابت امضا می‌شوند، پس نسخه‌ی جدید روی نسخه‌ی قبلی نصب می‌شود و
پروفایل‌ها از دست نمی‌روند.

## افزودن کانفیگ

- دکمه‌ی + → *Import config from clipboard* (یا اسکن QR).
- برای کانفیگ دستی: نوع پروتکل را انتخاب کنید و مقادیر سرور را وارد کنید.

### پروفایل VLESS + REALITY + XHTTP

| فیلد | مقدار |
|---|---|
| Address / Port | آی‌پی سرور، پورت ۴۴۳ (یا ۸۴۴۳/۲۰۵۳ اگر باز است) |
| Security | `reality` |
| SNI | یک دامنه‌ی واقعی TLS 1.3 بدون کلادفلر (همان چیزی که روی سرور تنظیم شده) |
| Public key / Short id / SpiderX | از پنل سرور |
| Fingerprint | `chrome` |
| Network | `xhttp` |
| XHTTP Mode | `packet-up` (یا `stream-up` اگر سرور پشتیبانی می‌کند) |
| Flow | **خالی** (vision فقط با TCP + REALITY کار می‌کند) |

## دو دکمه‌ای که باید بشناسید

- **پریست ایران** (در ویرایش پروفایل): فینگرپرینت، `dialMode: oob.0` و `finalMask: merge` را
  یک‌جا تنظیم می‌کند.
- **کپی اطلاعات تشخیصی** (در صفحه‌ی درباره): یک متن کوتاه و بی‌خطر (بدون آدرس، پورت، UUID)
  برای فرستادن هنگام بروز مشکل.

## شکل ترافیک

این نسخه اعداد ثابت را حذف می‌کند تا الگوی ترافیک شبیه یک عدد تکرارشونده نباشد:

| پارامتر | بازه‌ی نمونه‌گیری (هر اتصال) |
|---|---|
| `finalMask` → `times` | ۶۰ تا ۱۶۰ |
| `finalMask` → `delayMs` | ۱۸ تا ۴۵ میلی‌ثانیه |
| `finalMask` → `maxBytes` | ۸ تا ۲۸ کیلوبایت |
| `scMinPostsIntervalMs` | ۲۲ تا ۵۵ میلی‌ثانیه |
| `xpaddingBytes` | پنجره‌ی ۱۵۰ تا ۹۰۰ بایت |

اگر خودتان یکی از این مقادیر را در `XHTTP Extra` یا `finalMask` بنویسید، همان مقدار شما
دست‌نخورده می‌ماند؛ فقط کلیدهای خالی پر می‌شوند.

**راه خاموش‌کردن:** در `XHTTP Extra` مقدار `"scMinPostsIntervalMs": 20` را دستی بگذارید و
پریست ایران را نزنید.

## محدودیت‌ها (صادقانه)

- اگر آی‌پی سرور بسته شده باشد، هیچ تنظیمی در کلاینت نجاتش نمی‌دهد.
- نسخه‌ی `lite` هسته‌های Aether/Psiphon/Tor را ندارد؛ برای آن‌ها نسخه‌ی `cores=all` لازم است.
- REALITY فقط روی TCP کار می‌کند؛ با XHTTP هم `flow` باید خالی بماند.
- mux یک تنظیم سراسری است؛ اگر روشن باشد، پریست آن را خاموش نمی‌کند.
