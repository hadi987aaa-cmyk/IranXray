# IranXray

کلاینت اندروید مبتنی بر Xray برای مدیریت و استفاده از کانفیگ‌های پروکسی.

**وضعیت پروژه: نسخه آزمایشی اولیه (Alpha)**

این مخزن بر پایه PattNG و v2rayNG ساخته شده است. هدف IranXray توسعه تدریجی یک کلاینت قابل‌اعتماد با تمرکز بر شبکه‌های محدودشده، پایداری اتصال و ابزارهای عیب‌یابی شبکه است.

## اصول توسعه

- هسته Xray با حفظ سازگاری کانفیگ‌ها
- پشتیبانی از VLESS، VMess، Trojan، Shadowsocks و پروتکل‌های موجود در هسته
- پشتیبانی از Reality و XHTTP مستقیم؛ وابستگی به Cloudflare برای مسیر اصلی اتصال در نظر گرفته نمی‌شود
- ابزار تشخیص DNS، IPv4/IPv6، برقراری TCP/TLS و خطاهای اتصال
- تنظیمات پیشرفته به‌صورت اختیاری و قابل آزمایش، نه فعال‌سازی پیش‌فرض گزینه‌های ناشناخته

## ساخت APK آزمایشی

از GitHub Actions، گردش‌کار **Build IranXray Debug APK** را اجرا کن. خروجی APK در بخش Artifacts همان اجرای Workflow قرار می‌گیرد.

## نکات مهم

- این پروژه در مرحله توسعه است و هنوز تضمینی برای کارکرد روی همه اپراتورها و شبکه‌ها ندارد.
- قابلیت‌های آزمایشی باید روی شبکه واقعی و با ثبت نتیجه آزموده شوند.
- کانفیگ‌ها و اطلاعات محرمانه را در Issueها یا گزارش‌های عمومی منتشر نکن.

## کد منبع و مجوز

IranXray یک اثر مشتق‌شده از [PattNG](https://github.com/patterniha/PattNG) و [v2rayNG](https://github.com/2dust/v2rayNG) است. مجوز GPL-3.0 و اعلان‌های حق‌نشر و مجوز فایل‌های منبع حفظ می‌شوند. لطفاً پیش از توزیع نسخه‌های مشتق‌شده، الزامات مجوز را رعایت کن.
